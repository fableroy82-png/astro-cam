# OpenNGC

Crédit : Mattia Verga et les contributeurs du projet [OpenNGC](https://github.com/mattiaverga/OpenNGC).

`OpenNGC_NGC.csv` et `OpenNGC_addendum.csv` sont les copies locales utilisées par l'UNO Q, récupérées sans modification de contenu le 17 octobre 2026. Le commit amont exact n'est pas connu. Les noms locaux correspondent respectivement à `database_files/NGC.csv` et `database_files/addendum.csv` en amont.

Ces données sont distribuées sous [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). La licence s'applique à ces catalogues ; elle n'attribue pas de licence au code Astro cam.

Les colonnes de provenance sont conservées. Le README et le guide du projet amont détaillent les sources astronomiques et les champs du catalogue.
