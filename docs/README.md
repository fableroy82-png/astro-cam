## Schémas

Les trois images nommées `ChatGPT Image…` sont des illustrations générées de conception, conservées telles que fournies. Elles n'ont pas été validées comme plans de fabrication ou de câblage. Vérifier les caractéristiques des composants, la numérotation des connecteurs et le brochage réel avant réalisation. Le firmware ST4 publié utilise D2–D5, alors que ces documents prévoient notamment D3–D6 ; ne pas les considérer comme interchangeables.
