# Supports de caméra

Assemblage et pièces Solid Edge, avec projets 3MF associés. Conserver les fichiers ensemble pour faciliter la résolution des références de l'assemblage `Asm2.asm`.

Les versions `support camera suiveur` et `support camera suiveur V2` sont conservées comme variantes de conception ; aucune validation dimensionnelle supplémentaire n'a été effectuée lors de la publication. Voir [le dossier matériel](../README.md).
